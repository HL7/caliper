# SDPi Microlearning Series

Short, standalone modules (10–15 minutes each) that give every stakeholder an accessible entry point into **SDPi** — Service-oriented Device Point-of-care Interoperability for medical devices. Modules can be taken on their own or combined into a learning path.

A Caliper Educational Project contributed by **Critical Software** and **Vector Informatik**.
